# Brandon Khumalo Portfolio

## Project Overview
A personal portfolio website for Brandon Khumalo, a Software Developer from Harare, Zimbabwe. Built with React, Vite, TypeScript, Tailwind CSS, and shadcn/ui components.

## Architecture
- **Framework**: React 18 with TypeScript
- **Build Tool**: Vite
- **Styling**: Tailwind CSS + shadcn/ui component library
- **Routing**: React Router DOM v6
- **Animations**: Framer Motion
- **Forms**: React Hook Form + Zod

## Project Structure
- `src/` - Main source code
- `public/` - Static assets
- `attached_assets/` - Project assets

## Development
- Run: `npm run dev` (starts on port 5000)
- Build: `npm run build`
- Lint: `npm run lint`

## Key Configuration
- Vite server configured on port 5000 with `allowedHosts: "all"` for Replit compatibility
- Path alias `@` maps to `src/`
